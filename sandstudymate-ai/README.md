# SandStudyMate AI

This project provides a study assistant that generates questions, evaluates answers, and exposes a lightweight web interface.

## Project structure

- `backend/` – Lambda/API logic
- `frontend/` – HTML, CSS, JavaScript UI
- `infrastructure/` – SAM/CDK-style infrastructure templates
- `docs/` – Product, architecture, and API documentation
- `tests/` – Test suite
