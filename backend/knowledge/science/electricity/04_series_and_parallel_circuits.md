# Series and Parallel Circuits

## Series circuits: one path

In a **series circuit**, components are connected one after another along a single path. Current has only one route through the circuit.

If one bulb is removed and this breaks the path, all bulbs in that series circuit go off.

**Simple picture in words:** Battery → Bulb A → Bulb B → back to battery.

## Parallel circuits: more than one path

In a **parallel circuit**, there are multiple branches that connect across the power source. Charge has more than one path to travel.

If one bulb in one branch is removed, other complete branches can continue working. This is a major reason parallel connections are useful in buildings.

**Simple picture in words:** One battery sends current through two separate branches: one with Bulb A and one with Bulb B. Both branches reconnect to the battery.

## Compare them

| Feature | Series | Parallel |
|---|---|---|
| Number of paths | One | Two or more branches |
| If one bulb is removed and its path breaks | All go off | Other complete branches can remain on |
| Where it is useful | Some simple learning circuits | Many household circuits |

## Do bulbs always have the same brightness?

Brightness depends on the battery, bulbs, and how they are connected. For **two identical bulbs with the same ideal battery**, bulbs connected in series are generally dimmer than each bulb would be if connected alone. In parallel, each bulb can receive the battery's full voltage. Real batteries may behave differently, especially if too much current is drawn.

## Check your understanding

**Question:** Which circuit lets another bulb stay on if a bulb in a different branch goes out?

**Answer:** A parallel circuit, as long as the other branch remains complete.
